# ThriveCV

A paperless CV. A living page you keep, not a file you reprint.

This repository is the public landing site: waitlist, product, plans, and a live CV preview (Amara, Tomas, Hana).

## What it is

You send `thrive.cv/you`. They open a page. There is no attachment to lose or reprint. Unlisted by default; PDF only if a portal still demands a file.

## Run it

```bash
npm install
npm run dev
```

Then open the URL Vite prints.

## Stack

TanStack Start, React, Tailwind. Waitlist emails stay in the browser (`localStorage`) until a backend is wired.
